2.4.2
Control de salidas digitales
Una salida escribe HIGH o LOW para ordenar una acción. El pin controla la señal; una etapa adecuada debe suministrar la potencia que requiera la carga.
Configuración
PIN = LOW
Respuesta
LED apagado
Programa
Seguridad: un LED necesita limitar corriente y las cargas inductivas o de mayor potencia requieren una interfaz apropiada. Nunca conectes directamente una carga de potencia al pin del microcontrolador.
Actividad 2 · Protege el dispositivo
Se necesita accionar un relé cuya bobina supera la corriente permitida por el pin. ¿Qué solución corresponde?

const int PIN_PUERTA = 2;
const int PIN_SISTEMA = 3;
const int PIN_VENTILADOR = 8;
const int PIN_ALARMA = 9;
const int PIN_TEMPERATURA = A0;

void setup() {
  pinMode(PIN_PUERTA, INPUT_PULLUP);
  pinMode(PIN_SISTEMA, INPUT_PULLUP);
  pinMode(PIN_VENTILADOR, OUTPUT);
  pinMode(PIN_ALARMA, OUTPUT);
}

void loop() {
  bool puertaAbierta = digitalRead(PIN_PUERTA) == LOW;
  bool sistemaActivo = digitalRead(PIN_SISTEMA) == LOW;
  int lecturaADC = analogRead(PIN_TEMPERATURA);
  float temperatura = lecturaADC * 100.0 / 1023.0;

  bool ventilador = sistemaActivo && temperatura >= 60.0;
  bool alarma = sistemaActivo && (puertaAbierta || temperatura >= 85.0);

  digitalWrite(PIN_VENTILADOR, ventilador ? HIGH : LOW);
  digitalWrite(PIN_ALARMA, alarma ? HIGH : LOW);
}
El modelo supone que el sensor entrega linealmente 0–100 °C para códigos ADC 0–1023. En una implementación real debe utilizarse la ecuación y el acondicionamiento indicados por el sensor elegido.
Antes del montaje: verifica niveles de tensión, corriente máxima de los pines, tierra común y necesidad de transistor, relé, diodo de protección o fuente externa. Las conexiones de potencia deben permanecer separadas de la lógica de bajo voltaje.

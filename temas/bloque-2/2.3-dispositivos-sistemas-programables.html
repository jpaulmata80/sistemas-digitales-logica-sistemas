2.3.1

Evolución de los sistemas digitales

La evolución redujo tamaño y consumo, aumentó la integración y permitió definir funciones mediante programas o configuraciones de hardware.

Idea central: programable no significa que el hardware desaparezca; significa que su comportamiento puede definirse o configurarse para cumplir una función.
2.3.2

Lógica cableada frente a lógica programable

Ambas implementan funciones digitales, pero difieren en la forma de construirlas y modificarlas.

Lógica cableada

La función se obtiene mediante componentes y conexiones específicas.

Fortaleza: solución directa para una función fija.

Lógica programable

La función se define mediante software o una descripción de hardware.

Fortaleza: adaptación, integración y reutilización.

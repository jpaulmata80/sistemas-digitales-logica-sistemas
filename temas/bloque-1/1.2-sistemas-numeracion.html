1.2.1

Sistemas posicionales y base

El valor de un dígito depende del símbolo utilizado, de su posición y de la base del sistema.

¿Qué significa la base?

La base indica cuántos símbolos diferentes utiliza el sistema. En base 2 solo se permiten 0 y 1; en base 16 se utilizan 0–9 y A–F.

SistemaBaseSímbolos permitidos
Binario20, 1
Octal80–7
Decimal100–9
Hexadecimal160–9, A–F

Valor posicional

Cada posición representa una potencia de la base. En el número binario 10110, la posición situada más a la derecha corresponde a 20.

101102=1×24+0×23+1×22+1×21+0×20=2210

1.2.2

Conversión entre decimal y binario

Para pasar de binario a decimal se suman pesos; para pasar de decimal a binario pueden utilizarse divisiones sucesivas entre 2.

Constructor binario de 8 bits

Activa o desactiva cada bit. Los pesos se suman automáticamente.

1286432168421
00000000₂ = 0₁₀
No hay pesos activos.

Decimal → binario

Divide sucesivamente entre 2 y conserva cada residuo. El número binario se obtiene leyendo los residuos desde el último hasta el primero.

45 ÷ 2 = 22, residuo 1 22 ÷ 2 = 11, residuo 0 11 ÷ 2 = 5, residuo 1 5 ÷ 2 = 2, residuo 1 2 ÷ 2 = 1, residuo 0 1 ÷ 2 = 0, residuo 1 Lectura inversa: 101101₂

1.2.3

Conversión rápida con octal y hexadecimal

Como 8 y 16 son potencias de 2, cada dígito octal representa tres bits y cada dígito hexadecimal representa cuatro bits.

Binario ↔ octal

Agrupa los bits de tres en tres desde la derecha. Si falta algún bit a la izquierda, completa con ceros.

110101102=3268

Binario ↔ hexadecimal

Agrupa los bits de cuatro en cuatro. Los valores decimales 10–15 se representan mediante A–F.

110101102=D616

1.2.4

Aplicaciones en sistemas digitales

La base se elige por legibilidad y utilidad. El circuito conserva bits; las personas utilizan notaciones más compactas para analizarlos.

Caso profesional · Campo de una trama

Un analizador muestra el campo de 8 bits 10101100₂. El reporte técnico solicita registrar el mismo valor en decimal y hexadecimal.

Selecciona la pareja que representa el mismo patrón.

¿Dónde aparece cada notación?

  • BinarioEstados de bits, máscaras, registros y señales internas.
  • DecimalValores dirigidos a usuarios y numerosos campos de configuración.
  • HexadecimalDirecciones MAC, IPv6, volcados de memoria y registros.
  • OctalRepresentación compacta histórica y permisos en sistemas tipo Unix.
